# Talent Matcher — Streamlit Candidate Matching Engine
A candidate filtering and ranking dashboard built with Python, Pandas, and Streamlit.

This project demonstrates how structured and semi-structured candidate data (Excel) can be ingested, normalized, scored, filtered using boolean logic, and surfaced through an interactive analytics UI.

# Project Overview
Talent Matcher is a rule-based candidate evaluation engine that:
- Ingests raw Excel candidate data
- Standardizes messy column naming conventions
- Parses free-text skills into structured tokens
- Supports boolean skill expressions (AND, OR, parentheses)
- Applies multi-dimensional filters (experience, location, domain tags, work authorization)
- Computes a transparent match score
- Ranks candidates dynamically
- Exports shortlist results to CSV

# The application provides an interactive UI for recruiters or hiring managers to refine candidate searches in real time.
